หน้านี้เป็น**บทตัวอย่าง** ที่โชว์ทุกอย่างที่ template ทำได้ ใช้เป็นแบบตอนเขียนบทจริง เมื่อเริ่มวิชาใหม่ลบโฟลเดอร์ `src/chapters/00-getting-started` กับ `01-widgets` ทิ้ง แล้วแก้รายชื่อบทใน `src/site.config.ts`

## เริ่มวิชาใหม่ใน 4 ขั้น

1. **แก้ `src/site.config.ts`** ชื่อเว็บ, ชื่อวิชา, สีธีม, รายชื่อบท และแผงตารางลอย (หรือปิดไปเลย)
2. **สร้างโฟลเดอร์บท** เช่น `src/chapters/01-intro/content.mdx` แล้วใส่ `Content: lazy(() => import('./chapters/01-intro/content.mdx'))` ในรายการบท
3. **เขียนเนื้อหา**ด้วย Markdown + กล่องต่างๆ ด้านล่าง (ไม่ต้อง import อะไร)
4. **`npm run dev`** เพื่อดูผลสด หรือ push ขึ้น GitHub แล้ว Actions จะ deploy ขึ้น Pages ให้เอง

## สูตรคณิต (KaTeX)

ในบรรทัดใช้ `$…$` เช่น $\sigma^2 = E[(X-\mu)^2]$ · แยกบรรทัดใช้ `$$…$$`

$$
\bar X \sim N\!\left(\mu,\ \frac{\sigma^2}{n}\right), \qquad z = \frac{\bar x - \mu_0}{\sigma / \sqrt n}
$$

สูตรถูก render ตอน build จึงเปิดเร็วและใช้ offline ได้

## ตาราง

| เครื่องหมาย | ความหมาย | ตัวอย่าง |
|---|---|---|
| $\mu$ | ค่าเฉลี่ยประชากร | $\mu = 170$ |
| $P(A \mid B)$ | ความน่าจะเป็นแบบมีเงื่อนไข | ใช้ `\mid` แทน `\|` ในตาราง |
| $\alpha$ | ระดับนัยสำคัญ | $5\%$ |

<Warn title="ข้อควรระวังเวลาเขียน MDX">

- เครื่องหมาย `<` และวงเล็บปีกกานอกสูตรต้อง escape เป็น `\<` หรือใส่ไว้ในสูตร
- เนื้อหาในกล่องต้องเว้นบรรทัดว่างก่อนและหลัง และห้ามย่อหน้าด้วย space
- `title="…"` ต้องเป็นข้อความธรรมดา ใส่สูตรไม่ได้
- ในตารางห้ามใช้ `|` ในสูตร และ `%` ในสูตรต้องเขียนเป็น `\%`

</Warn>

## ฟีเจอร์อื่นๆ ที่มีให้แล้ว

- **จำตำแหน่งที่อ่าน** ของแต่ละบท และเปิดบทล่าสุดให้อัตโนมัติ (เก็บในเบราว์เซอร์)
- **แถบความคืบหน้า** ด้านบน และ**สารบัญ**ที่ไฮไลต์หัวข้อที่กำลังอ่าน
- **แผงตารางลอย** ปุ่มมุมขวาล่าง (ตั้งแท็บได้ใน config) ลองกดดู มีตาราง z / t / χ² และแท็บตัวอย่าง
- **ธีมสี** 9 สี × 3 พื้นหลัง × สว่าง/มืด/ตามเครื่อง ตั้งใน `theme` ของ config
- **build ออกมาเป็นไฟล์ HTML ไฟล์เดียว** (`dist/index.html`) ส่งให้เพื่อนหรือเปิดจากเครื่องได้เลยไม่ต้องมีเน็ต
